# AMVF2 — v15 — Recibos profissionais

A v15 mantém a base funcional da v14 e melhora somente a apresentação dos recibos de pagamento.

## Melhorias
- Logo AMVF2 no cabeçalho do recibo.
- Identificação completa da associação.
- Título de recibo mais formal.
- Dados do associado, competência, forma e data do pagamento.
- Valor recebido em destaque.
- Campos de assinatura.
- Data/hora de geração.
- Layout preparado para impressão A4 e para "Salvar como PDF".
- Botões de imprimir/fechar que não aparecem no documento impresso.
- Escapamento dos dados exibidos no recibo para evitar problemas com caracteres especiais.

Não há alteração de planilha, Apps Script, usuários, permissões, financeiro ou demais módulos.

## v16 — acesso ao recibo
O recibo de mensalidade fica disponível na ficha financeira do morador, ao lado de cada pagamento de Taxa Mensal, no botão **Recibo**.
